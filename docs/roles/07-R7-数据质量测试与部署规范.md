# 07 R7 数据、质量、测试与部署规范

## 1. 责任边界

R7 主责首发城市知识/规则数据建设、数据质量、脱敏评估集、模型与 Prompt 效果评估、测试体系、部署及运维。R7 不能绕过 R3 的审核流程直接发布规则，不能以演示效果修改生产事实数据。

## 2. 数据建设规范

- M0 冻结首发城市清单、实体编码规则、资料模板、来源许可、核验频率和负责人。数据录入须有双人复核或等效审核，记录 URL/许可、时间、城市、版本、审核状态。
- 建立景点、别名、POI、开放时段、预约政策、票价、图片、餐饮住宿和节假日样本的完整性/唯一性/时效性规则；同名/别名冲突进入人工队列，禁止自动合并。
- 规则过期、来源失效、图片版权不明、异常价格、坐标漂移应告警并下线确定性结论；历史来源快照永久可解释。

## 3. 质量评估集与模型评估

- 至少建立 30 个脱敏案例，覆盖亲子、老人、摄影、雨天、跨城、预算紧、必去/闭馆冲突、长期日期、无数据城市、局部单点/单日/跨日修改、Agent 故障和社区复用。
- 每例定义输入、允许事实来源、硬约束、人工基线、预期降级、评分方式和回归版本。指标至少有硬约束违反数、来源完整率、过期标示率、路线可行率、未影响区块保真率、P95 时延、token/API 成本和用户可理解性。
- 与 TripStar 比较须在相同脱敏输入、固定日期/供应商条件下人工执行；保存摘要、评分和坏例，不复制其代码/数据。模型更换、Prompt、Schema、算法、数据集更新必须触发回归。

## 4. 测试门禁

- 单元：算法、时间/时区、预算、积分守恒、权限、规则时效、文本/文件安全。
- 集成：Testcontainers MySQL/Redis、Flyway 空库升级、适配器 Mock、任务重试恢复、事件幂等、缓存 TTL。
- 契约：全部 Agent Schema 正反例、OpenAPI 消费者、兼容性；E2E：生成→修改→导出→发布→举报/下架→失败退款。
- 安全：密钥/依赖/许可证扫描、IDOR、XSS、SSRF、上传、Prompt 注入、日志泄露；性能：并发、队列、缓存、模型/供应商 429、磁盘和恢复演练。

## 5. 部署、观测与恢复

- 裸机用受限运行账号、独立数据目录、systemd/Windows 等效启动、健康检查、端口清单、TLS、日志轮转和最小文件权限；开发 Compose 不等同生产方案。
- 监测服务健康、任务状态、Worker 租约、队列积压、失败率、缓存命中、第三方配额/429、模型 token/成本、MySQL 连接/慢查询、Redis、磁盘、备份和来源过期率；告警应有负责人和处置手册。
- 备份 MySQL、对象文件、配置和密钥恢复流程；定期在隔离环境恢复，并校验版本/来源引用、积分守恒、任务可读、文件授权。生产禁止手改库和删审计/流水。

## 6. 发布 Gate

发布前提供数据质量报告、评估回归、测试报告、安全扫描、性能结果、已接受风险、回滚方案和恢复演练记录。任何无来源事实、硬约束违反、跨用户数据泄露、重复扣退积分、不可恢复迁移或无法恢复备份均为 NO-GO。

## 7. 逐步开发提示词

### R7-00 建立质量门禁与数据模板

```text
请创建 docs/data/ 数据字典、来源许可模板、首发城市清单、脱敏样例和质量规则；创建 tests/ 的目录、测试命名规范和 CI 门禁清单。
先列出待确认城市、供应商、时效阈值和许可问题，均标 PENDING；不得为了填满知识库编造景点、票价、天气或图片。
```

### R7-01 首批数据建设与校验

```text
按照 R3 模板导入一个试点城市的景点、POI、开放时段、预约规则、票价和图片元数据草稿。
执行唯一性、坐标、来源/许可、有效期、同名、异常价格、图片魔数和 EXIF 检查；输出错误清单和双人复核记录，不直接发布生产数据。
```

### R7-02 建立评估集与人工基线

```text
创建至少 30 个脱敏案例，包含硬约束、天气/闭馆、无数据城市、预算、亲子/老人、局部修改、故障降级和社区复用。
为每例定义允许来源、期望降级、人工评分表和 TripStar 对照记录；固定输入和日期后跑一次基线，保存摘要与坏例，不复制对方代码或数据。
```

### R7-03 自动化测试与故障注入

```text
实现 Java/Python/前端单元、契约、Testcontainers 集成、Playwright E2E、密钥/敏感日志扫描和依赖许可证扫描。
注入模型非法 JSON、地图/天气 429、Redis 重启、Worker 崩溃、重复消息、SSE 断线、文件扫描失败和积分确认后崩溃；验证状态恢复、退款、审计和来源完整，不关闭安全门禁。
```

### R7-04 性能、部署与恢复

```text
按 M0 目标压测生成、修改、榜单、导出和登录，记录 P50/P95、队列积压、缓存命中、token/API 成本、MySQL/Redis/磁盘指标。
完善裸机启动/停止/状态/日志脚本、受限账号、健康检查、备份、对象文件同步、密钥轮换和隔离环境恢复。恢复后校验任务、版本、来源、积分守恒和文件授权，输出 GO/NO-GO 报告。
```
