# 08 R8 沉淀层与社区规范

## 1. 责任边界

R8 全栈主责榜单、社区动态流、历史行程记录与偏好分析、用户偏好记忆库、个人主页聚合页面，并兼项目 PPT 与各里程碑汇报/答辩材料；M0~M2 期间支援 R5 业务 CRUD（用户/行程打底）。前端遵循 R6 的组件规范与整体视觉风格，后端复用 R5 的认证/授权/共享治理基建与 R2/R3 产出的行程/来源数据。R8 不实现 Agent 决策、模型 Prompt、路线/天气算法；社区业务依赖的敏感词/文件安全/反刷/下架失效等公共能力由 R5 提供（见 05），R8 只负责社区的业务规则与交互。

## 2. 榜单与社区（2.4，本期一体两视图）

- 社区动态流是全量视图，先发后审：发布前执行敏感词/频率/归属/内容安全校验（复用 R5 公共能力），发布后默认进入动态流；人工抽审事后补充治理，不做「审核通过才可见」。
- 榜单是动态流的精选子集：满足推荐算法五维度（热度/评分/季节适配/行程合理性/人流量）加权分达标，或经管理员人工挑选，才进入分类榜单；二者共用同一套内容、评论、点赞、举报数据，不建两套。
- 分类榜单：按城市、按主题（亲子/徒步/摄影/美食等）、按天数（周末 2 日 / 3~4 日 / 一周深度）、可组合筛选。
- 推荐为加权评分制 + 时间衰减（首次不引入重型模型），评分公式、时间衰减、人工置顶/下架、反作弊阈值均可配置且可审计。
- 互动：点赞、评论（同样敏感词过滤）、收藏、一键复用（拷贝为草稿再走迭代，去除原作者私密偏好、个人备注和精确住宿/行程敏感信息）。UGC 图片校验魔数/MIME/尺寸、剥离 EXIF 定位信息，生成随机对象键与受权访问链接。
- 积分激励（可选亮点）：行程被复用或进入榜单时发布者获得少量积分（计入 2.7 钱包），对接 R5 积分账务接口。
- 治理：发布时校验，上榜后人工抽审，配合举报下架；下架后公开接口、搜索、缓存和榜单同时不可见。管理员（2.6）承接审核队列与榜单人工干预。

## 3. 历史记录与偏好分析（2.5.5）

- 覆盖平台生成行程（含历史版本）、复用榜单后修改的行程、手工编辑的行程；按时间/城市/天数/状态（草稿、已定稿、已出行、已上榜）筛选与搜索。
- 能力：再来一单（复制为新草稿进入迭代）、同行程版本演进对比；数据来自行程库 + 版本库 + 行为数据，无需新增采集。
- 偏好汇总分析：统计维度用规则聚合（SQL/离线任务），LLM 仅做画像文案表达；历史行程 <3 条时不出画像。反哺：结论写入偏好记忆库作软性输入，不参与榜单排序等公共场景。

## 4. 用户偏好记忆库（2.5.4）

- 借鉴 TripStar 机制、自研实现：行程生成成功后提取稳定偏好（节奏/口味/预算档）打分入库，下次规划注入高权重偏好作为软权重，不得覆盖用户当次显式输入。
- 每条偏好记录来源、置信度、权重、最后使用时间与可解释理由；用户可查看与清空；偏好数据本地存储，不进公共榜单、不得未脱敏传给模型供应商。

## 5. 个人主页聚合页（2.5.6）

- 聚合入口而非新数据模型：历史记录与偏好画像（2.5.5）、偏好记忆库查看/清空（2.5.4）、钱包余额与流水（2.7）、我的社区内容（2.4）、账户设置（2.6）。
- 只展示与操作当前登录用户自己的数据；各子项数据来源、权限与边界以其归属章节为准，本节不重复定义；账户设置与资料修改按 R5 的 2.6 规范执行。

## 6. 边界与禁止事项

- 社区/榜单/历史/偏好全部按登录用户归属过滤，公开内容仍须过滤下架/删除态。
- 复用仅复制允许复用的公开版本；一键复用、交互与积分奖励不得重复计（幂等）。
- 不得从单次行为过度推断敏感属性；不得把偏好用于公共榜单排序或管理员常规浏览；不得绕过 R3/R5 的审核与来源规范直接发布内容。

## 7. 逐步开发提示词

### R8-00 社区数据模型与治理基建对接

```text
请先与 R5 对齐社区/榜单/历史/偏好的数据模型与 Flyway 迁移（community_post、comment、like、favorite、report、moderation_case、preference_profile 等），复用 R5 的认证、授权与内容治理公共能力（敏感词/文件安全/反刷/下架失效）。
明确公开只读视图与按所有者过滤规则，先出数据字典与接口契约样例，不写完整业务；未确认规则记 PENDING。
```

### R8-01 榜单与社区动态流（先发后审）

```text
实现动态流、发布、点赞、评论、收藏、一键复用、举报、审核与分类榜单。发布前执行敏感词/频率/归属/文件安全校验（复用 R5）；下架后搜索、缓存、榜单同时不可见。
图片校验魔数/MIME/尺寸、剥离 EXIF、随机对象键、访问授权。榜单五维度加权分 + 时间衰减 + 人工置顶/下架，配置化与审计。
测试刷赞、重复提交、越权编辑、复用隐私清理、下架后缓存不可见、举报工单流转。
```

### R8-02 历史记录与版本演进

```text
实现历史行程记录的列表筛选、搜索、再来一单与同行程版本演进对比；数据来自行程库/版本库/行为数据，不新增采集。
公开与私有边界清晰：历史行程仅本人可见，公开榜单行程另走只读视图。测试跨版本对比、草稿状态流转、再来一单不污染原行程。
```

### R8-03 偏好提取、分析与记忆库

```text
实现偏好汇总分析与偏好记忆库。统计维度用规则聚合（SQL/离线任务），LLM 只写画像文案；历史 <3 条不出画像。
偏好注入为软权重，不覆盖用户当次显式输入；每条偏好带来源/置信度/权重/最后使用时间，可查看与清空。
测试样本不足、清空、重复提取、偏好不参与公共场景与脱敏传递。
```

### R8-04 个人主页聚合与最终验收

```text
实现个人主页聚合页（历史/画像/记忆库/钱包/我的社区/账户设置），仅展示与操作当前用户自己的数据，各子项边界以其归属章节为准。
钱包与账户设置复用 R5 接口，社区内容复用 R8-01。完成全栈验收并输出社区/历史/偏好/主页的接口、权限、审计与前端规范符合性报告。
```
