# 05 R5 业务后端与平台能力规范

## 1. 责任边界

R5 主责 Spring Boot 业务 API、账号权限、行程/任务持久化接口、队列与缓存基础设施、第三方适配器外壳、导出、提醒和积分（若需求版本包含钱包）。R5 不实现 Agent 决策、模型 Prompt、路线算法或前端视觉。榜单/社区/UGC 的业务由 R8 主责，R5 仅提供其所需的共享基建（内容治理敏感词/文件安全校验、反刷限流、下架缓存失效等公共能力），详见本文件第 4 节。

## 2. API、身份与数据权限

- REST/OpenAPI 先行，统一错误码、分页、校验和 `trace_id`。所有资源按登录用户归属过滤；ID 只用于查找，不代表授权。USER/ADMIN 权限逐接口定义，路由隐藏不视为安全措施。
- JWT 短期访问、刷新令牌安全存储与吊销；登录限流、密码哈希、会话失效、CORS/CSRF、SSE 鉴权均测试。业务后端是唯一 MySQL 写入方，Agent 回写仅能使用受限服务身份和 task 级授权。
- 任务创建、步骤回写、版本确认、导出和提醒均含状态/版本检查与幂等键；消息消费使用唯一事件 ID、租约、重试和死信，不依赖“至少一次”就天然正确。

## 3. 适配器、缓存与任务基础设施

- 为地图/POI/天气/LLM 提供统一端口、超时、重试、熔断、配额、Mock、脱敏日志和供应商切换；Agent 不能绕过适配层。
- 缓存键含供应商、城市/坐标、日期时段、交通方式及所有影响结果参数，记录数据时间/TTL/版本；禁止缓存私密用户请求、认证失败和不带上下文的“景点名称路线”。缓存失效不等于数据仍可作事实。
- 进度以 task_id + sequence_no 持久化/推送，断线补拉、乱序去重。失败任务保留可复用且新鲜的采集结果，但只能在来源/参数完全匹配时复用。

## 4. 共享能力：社区治理基建、导出、提醒与钱包

- 社区/榜单/UGC 业务由 R8 全栈主责；R5 只提供共享基建与公共能力：敏感词/频率/归属/内容安全检查（发布前执行）、下架态在动态流/榜单/搜索/缓存同时生效、点赞/评论/收藏/举报的唯一约束与防刷限流、反 XSS、一键复用去除原作者私密字段、审核/举报/下架的审计与缓存失效。R8 在其规范中定义社区业务与交互，R5 保证这些公共能力可被 R8 复用。
- 导出异步化，按所有者授权、短期签名链接、水印、下载审计和过期清理执行；防 IDOR、枚举、路径穿越、SSRF 和恶意图片。ICS 处理时区、UID、转义与全天事件。
- 提醒仅站内消息，按用户授权、规则时区、去重、取消和过期状态投递；天气重查只在进入预报期且有显著变化时触发。
- 积分已启用：余额只由只追加整数流水计算/维护；预扣、确认、退款、赠送、模拟充值、管理员调整都用唯一业务引用和事务。服务端校验 quote/套餐/方案数，绝不信任前端金额；重复消息与崩溃恢复不得重复扣退。

## 5. 验收与常见问题

至少覆盖 IDOR、管理员越权、并发生成、重复消息、Worker 重启、缓存污染、导出跨用户、图片路径绕过、下架缓存残留、提醒重复、积分临界余额与对账守恒。禁止前端直连数据库、Agent 共享业务库账号、真实支付接口、通过删除流水“修余额”、同步长事务等待模型输出。

## 6. 逐步开发提示词

### R5-00 工程与数据库骨架

```text
请初始化 Spring Boot 业务服务、MySQL/Flyway、Redis、统一错误/分页/审计接口和健康检查，不实现页面和 Agent 决策。
表使用 InnoDB、utf8mb4、小写蛇形、UTC DATETIME(6)、版本号和必要索引；创建空库升级、回滚演练和 SQL/MySQL 兼容检查。配置和密钥只能从环境注入。
```

### R5-01 账号、权限和资源归属

```text
实现 USER/ADMIN 登录、密码哈希、JWT/刷新/退出、限流锁定和逐接口授权。
对 task、itinerary、version、wallet、export、community 逐项验证 owner/role；测试伪造 user_id、IDOR、过期令牌、并发刷新、SSE 鉴权和登出断连。每次登录、拒绝和高风险管理操作写审计。
```

### R5-02 任务、适配器、缓存与进度

```text
实现 planning_task/task_step REST、事务 Outbox、Redis Streams Consumer Group、租约心跳、幂等事件和 SSE 进度补拉。
接入地图/天气/POI/LLM 适配器外壳，统一超时、重试、熔断、quota 和缓存键/TTL；不允许 Agent 直连供应商。测试重复消息、Worker 崩溃、缓存污染和第三方 429。
```

### R5-03 行程版本、导出与提醒

```text
实现行程/版本只读写接口、来源快照引用、导出任务、短期授权链接、水印、下载审计和站内提醒。
PDF/ICS/长图失败不能修改计划；处理时区、UID、SSRF、恶意图片、路径穿越、过期链接和跨用户下载。提醒去重、可取消、规则过期时不发送确定性内容。
```

### R5-04 社区共享基建与内容治理能力

```text
实现供 R8 社区/榜单/UGC 复用的共享基建与公共能力（社区业务与交互由 R8 主责）。
提供：敏感词/频率/归属/文件安全校验（发布前执行）、下架态在搜索/缓存/榜单/动态流同步生效、点赞/评论/收藏/举报的唯一约束与防刷限流、反 XSS、一键复用隐私字段清理、审核/举报/下架审计。
图片校验魔数/MIME/尺寸、剥离 EXIF、随机对象键；文本不使用不安全 HTML。补刷赞、重复提交、越权编辑和复用隐私清理测试。
```

### R5-05 积分与最终后端验收

```text
按开发决策基线实现 quote、预扣、确认、退款、赠送、模拟充值和管理员调整的只追加整数流水及唯一业务引用。
后端服务端校验套餐/方案数/余额，事务内保证守恒；测试并发临界余额、重复回调、任务失败重试、服务崩溃恢复、重复退款和对账。最后输出 API、迁移、权限、审计、性能和恢复报告。
```
