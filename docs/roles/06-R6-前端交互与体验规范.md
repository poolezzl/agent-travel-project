# 06 R6 前端交互与体验规范

## 1. 责任边界

R6 负责参数表单、登录态、任务进度、行程时间轴/地图、对话修改、方案对比、版本 diff、榜单/社区界面和移动端适配；前端不得承担授权裁决、余额计算、事实生成或数据库访问。

## 2. 数据与状态规范

- 以 OpenAPI 生成/约束 TypeScript 类型，不复制一套手写字段；API/Schema 升级先处理 unknown/optional 字段，禁止前端静默吞掉 `degraded_fields`、来源和时效信息。
- 界面显式展示排队、处理中、待确认、部分完成、失败、取消、退款与完成。流式事件按 `sequence_no` 去重，断线后通过任务查询补齐；旧事件不可覆盖较新版本/状态。
- 所有事实数据展示来源、更新时间和“预报/统计/估算/待核验”标识；预算区分总额/人均、精确/区间/未知。无数据用空态，不填假数字或“暂无问题”。

## 3. 核心交互要求

- 表单校验城市、日期、人数、预算、必去点和明显不可行组合；仍以服务端结果为准。提交按钮防连点并复用 idempotency key，失败重试让用户明确选择。
- 修改页面显示基准版本、影响范围、将重跑的 Agent、变更 diff 和保护项；涉及必去点/预约/锁定内容先确认。回滚创建新版本后的时间线要可理解，不显示“历史被删除”。
- 地图使用受限前端 JS Key；点位以 POI ID 渲染，处理无坐标/估算路线/跨日。不要把地图 SDK 错误、密钥或内部响应展示给用户。
- 导出、发布、举报、删除、积分调整等高风险动作有二次确认、进行中状态和最终结果；下载链接不持久化到浏览器存储。

## 4. 安全与可用性

- 不使用 `v-html` 渲染 UGC、模型或供应商文本；使用白名单 Markdown 渲染和 URL 协议白名单。图片懒加载、失败占位、无 EXIF 位置信息回显。
- 不在 localStorage 保存刷新令牌、完整私密行程或偏好档案；退出后清理内存缓存与 SSE 连接。所有错误页只显示用户可操作信息和 trace 短码。
- 覆盖窄屏、弱网、长行程、大字号、键盘操作、色彩对比、加载骨架和网络中断。移动端不因地图/图片加载而阻塞行程文字可读性。

## 5. 验收

对每个状态、来源/降级、版本冲突、断线重连、重复点击、无权限、XSS 文本、图片失败、长文本和移动端进行 Playwright/Vitest 覆盖。阻断项：隐藏降级/过期提示、前端计算/信任余额、直接渲染不可信 HTML、旧进度覆盖新版本、仅凭前端隐藏实现权限。

## 6. 逐步开发提示词

### R6-00 前端骨架与设计系统

```text
请初始化 Vue 3 + TypeScript + Vite、路由、状态管理、API 客户端、错误边界、鉴权守卫和基础组件，不实现完整业务页面。
从 OpenAPI 生成/校验类型；统一金额、日期、时区、来源标签、加载/空/错误状态和移动端断点。不得把权限判断、余额计算或事实生成放在前端。
```

### R6-01 登录、表单与任务提交

```text
实现登录/退出/刷新、参数表单、城市/日期/人数/预算校验、方案数量和提交防连点。
访问令牌短期保存在安全内存方案，不能把刷新令牌、完整私密行程或偏好写 localStorage；提交生成使用服务端报价与 idempotency key。测试未登录、余额不足、过期令牌、重复点击和服务端校验失败。
```

### R6-02 进度流与行程展示

```text
实现排队、解析、采集、路线、整合、待确认、部分、失败、取消、退款、完成状态视图。
SSE 事件按 sequence_no 去重并支持断线补拉；所有命令使用 REST。行程时间轴、地图、预算、天气、预约和每个事实字段显示来源/更新时间/估算标记。不得用空值补“看起来完整”的结果。
```

### R6-03 对话修改、方案对比与 diff

```text
实现问答/修改入口、影响范围、保护项、确认弹窗、方案对比、版本时间线、diff 和回滚入口。
询问不建版本；旧 ETag 冲突显示服务端新版本差异；未影响日期保持可验证不变。测试单点、单日、跨日、拒绝确认、并发修改、降级和失败重试。
```

### R6-04 社区、导出与移动端验收

```text
实现榜单/动态流/评论/点赞/举报/复用、导出和提醒页面。
不安全 HTML 使用白名单渲染，图片懒加载、失败占位，导出链接短期且不持久化；验证下架后缓存不可见、权限错误可理解、弱网/窄屏/键盘/大字号可用。提交 Playwright、Vitest、无障碍和移动端报告。
```
