# ADR-0004：事实来源快照

- 状态：Accepted
- 日期：2026-09-20
- 决策者：R1，R2，R3

## 上下文

地图、天气、知识和预约规则会变化。只保存最终文案无法复现计划，也无法证明事实未由模型编造。

## 决策

最终版本引用不可变来源快照。每个事实至少关联来源类型、内部记录或脱敏供应商摘要、取得时间、有效期、新鲜度、估算标识和内容哈希；不保存密钥、完整敏感响应或受限原文。多方案在同一新鲜快照上计算。

## 后果与验证

存储量增加，但版本可回放。契约和质量测试必须做到事实到快照的完整引用、过期可见、哈希可复算；无来源事实阻断发布。

## 替换与回滚

来源格式升级采用版本化新字段和迁移读取器，不原地改写已发布版本引用。
