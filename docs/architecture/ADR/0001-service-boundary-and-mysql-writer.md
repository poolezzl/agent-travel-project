# ADR-0001：Java/Python 服务边界与 MySQL 唯一写方

- 状态：Accepted
- 日期：2026-09-20
- 决策者：R1，R5

## 上下文

业务身份、任务、版本、积分和审计要求同一事务边界；Agent 编排需要 Python 生态。双栈共享数据库会绕过授权、迁移和一致性规则。

## 决策

Spring Boot 是业务 API 和 MySQL 的唯一写方。FastAPI/LangGraph 只通过 S02 OpenAPI 读取最小任务上下文并回写结构化步骤结果；Python、前端和子 Agent 均不得直连业务表。总控是唯一用户意图入口，专业 Agent 之间不互调。

## 后果与验证

跨栈调用增加一次网络边界，但授权、幂等、审计和迁移集中。消费者契约测试必须证明 Python 无数据库配置、Java 校验回写身份/状态/attempt，网络失败可重试且不重复写。

## 替换与回滚

若未来合并服务，必须新 ADR、数据所有权迁移和双写禁止证明；当前实现偏离时回滚到仅 REST 回写。
