# ADR-0006：缓存所有权与新鲜度

- 状态：Accepted
- 日期：2026-09-20
- 决策者：R1，R2，R3，R5

## 上下文

路线、天气、POI、知识和规则的参数、时效与降级不同。共享无主缓存会跨城市污染并把错误当事实。

## 决策

适配器拥有其缓存命名空间、键版本、TTL、负缓存和失效规则；队列、缓存、限流使用不同 Redis 前缀。路线键包含坐标系/端点/方式/时段，天气键包含城市标准 ID/日期/供应商窗口。鉴权和配额错误不负缓存。缓存命中保留原来源时间并向用户展示新鲜度。

## 后果与验证

存在跨适配器重复数据，但责任清楚。测试键隔离、TTL 边界、脏数据、429、鉴权失败和版本升级；缓存不可作为业务事实来源。

## 替换与回滚

键语义变化使用新版本前缀；异常时停用对应命名空间并回源或显式降级，不批量猜测修复值。
