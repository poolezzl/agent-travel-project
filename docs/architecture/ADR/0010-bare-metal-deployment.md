# ADR-0010：裸机主部署

- 状态：Accepted
- 日期：2026-09-20
- 决策者：R1，R7

## 上下文

目标部署机无虚拟化条件，但开发环境仍需可重复启动依赖。

## 决策

生产交付以 Linux、Nginx、systemd、受限服务账号和独立目录为主，并提供 Windows PowerShell 等效脚本。Docker Compose 只用于本地依赖和换机备选，不能成为唯一部署路径。密钥使用环境或受限文件，备份写部署机外目录。

## 后果与验证

需要维护两套启动脚本和端口/权限清单。S30 必须测试开机自启、健康检查、日志轮转、TLS、最小权限、隔离恢复和 Windows 等效流程。

## 替换与回滚

未来容器化需新 ADR 和等价恢复证明；发布失败按版本目录和数据库迁移兼容规则回滚。
