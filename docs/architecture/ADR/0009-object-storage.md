# ADR-0009：受控对象文件

- 状态：Accepted
- 日期：2026-09-20
- 决策者：R1，R5，R8

## 上下文

UGC 图片和导出文件体积不适合写入 MySQL，但直接暴露本地路径会造成越权、路径穿越和生命周期失控。

## 决策

文件写入受控本地目录，随机对象键；MySQL 保存所有者、MIME、大小、哈希、许可、状态和有效期。下载经 Java 鉴权并签发短期能力链接，不接受用户路径。图片校验魔数/MIME/尺寸、剥离 EXIF；接口预留 MinIO 兼容而不提前引入。

## 后果与验证

数据库和文件需协调清理与备份。测试 IDOR、路径穿越、伪 MIME、恶意图片、过期链接、孤儿清理和恢复授权。

## 替换与回滚

迁移对象存储时保持对象键和元数据不变，双读校验后切换；失败回切本地受控目录。
