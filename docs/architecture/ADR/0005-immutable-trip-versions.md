# ADR-0005：不可变行程版本

- 状态：Accepted
- 日期：2026-09-20
- 决策者：R1，R4，R5

## 上下文

局部修改、回滚、并发编辑和审计要求能够证明哪些内容变化以及哪些区块保持不变。

## 决策

已发布行程版本不可原地更新。新版本保存父版本、结构化变更集、来源快照、Schema/模型/Prompt 版本和内容哈希；写入以 `base_version_id + ETag` 乐观锁校验。回滚创建新版本，确认前不创建版本，未影响区块按原引用复用。

## 后果与验证

需要版本保留和对象引用管理。测试旧 ETag 409、并发修改、拒绝确认、回滚和未影响区块哈希一致；任何直接 UPDATE 发布版本均视为阻断错误。

## 替换与回滚

版本模型变化需提供只读兼容和新版本迁移，不删除历史；失败提交整事务回滚。
