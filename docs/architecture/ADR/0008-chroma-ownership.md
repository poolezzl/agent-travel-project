# ADR-0008：Chroma 单一所有权

- 状态：Accepted
- 日期：2026-09-20
- 决策者：R1，R3

## 上下文

向量索引需与已发布知识版本一致。多服务直写会产生不可追踪的索引漂移，且 Chroma 不能成为审核状态的事实来源。

## 决策

Chroma 持久化实例只由 Agent 服务中的知识检索模块拥有，默认 Embedding 为可配置的 `bge-small-zh-v1.5`。Java/MySQL 保存知识、审核和版本事实；发布事件驱动幂等索引，检索结果必须回到 MySQL 校验城市、发布状态和有效期。

## 后果与验证

索引短暂滞后时宁可返回 unknown。测试重复索引、删除/回滚、重建、低相似度和注入文本；从 MySQL 可完整重建 Chroma。

## 替换与回滚

更换向量库或模型时使用新 collection/version 并灰度重建；失败切回旧索引，不改变知识事实。
