# ADR-0003：REST 命令与 SSE 进度

- 状态：Accepted
- 日期：2026-09-20
- 决策者：R1，R5，R6

## 上下文

规划任务耗时长，需要单向进度、断线恢复和鉴权；双向实时协议会增加当前范围不需要的复杂度。

## 决策

创建、取消、确认和查询全部走 Java REST；进度由 Java 鉴权后的 SSE 输出。事件先持久化，再以每任务单调 `sequence_no` 推送；客户端携带最后序号补拉并去重。前端不连接 Redis 或 Agent 服务。

## 后果与验证

需处理代理缓冲、心跳和连接上限。测试断线、重连、重复/乱序事件、越权订阅和终态关闭；旧事件不得覆盖新状态。

## 替换与回滚

未来若需双向协作可新 ADR 评估 WebSocket；SSE 故障时前端降级轮询任务查询，不改变命令语义。
