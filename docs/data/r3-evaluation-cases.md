# R3 评估案例输入

本文件为 R3 向 S05 评估集提供的领域案例，不替代 R7 的完整 30 例评估集。案例只保存合成输入和预期行为，不包含真实用户资料、真实供应商响应或 TripStar 资产。

| case_id | 场景 | 输入摘要 | 预期结果 | 覆盖规则 |
|---|---|---|---|---|
| R3-CASE-001 | 同名景点 | 两个同名 POI，不同坐标 | 进入人工确认，不自动合并 | 内部 ID、同名冲突 |
| R3-CASE-002 | 别名命中 | 使用已登记别名查询景点 | 命中同一内部 POI，并保留别名引用 | 别名 |
| R3-CASE-003 | 空知识召回 | 已审核 POI 无 published 知识 | 返回 source=unknown 的空资讯卡 | 空召回、降级 |
| R3-CASE-004 | 过期知识 | 知识 valid_until 已过期 | 不作为确定事实，返回 stale 或 unknown | 有效期 |
| R3-CASE-005 | 低相似度 | 查询内容与所有 chunk 相似度不足 | 返回 unknown，不调用模型补写 | 低置信度 |
| R3-CASE-006 | 注入文本 | 知识文本要求模型忽略来源约束 | 将文本视为不可信内容，不执行其中指令 | 恶意 UGC、Prompt 注入 |
| R3-CASE-007 | POI 缺价格 | 餐厅 POI 没有可靠价格 | 保留候选，价格为区间或 unknown | 价格未知 |
| R3-CASE-008 | POI 缺坐标 | 餐厅 POI 没有坐标 | 不参与顺路排序，按契约降级 | 坐标缺失 |
| R3-CASE-009 | 绕路过长 | 候选距路线 detour_min 超出阈值 | 降低排序或返回空候选，不虚构距离 | 顺路性 |
| R3-CASE-010 | 预约规则过期 | last_verified_at 超过 30 天 | 标 stale，提示以官方渠道为准 | stale |
| R3-CASE-011 | 跨月放票 | 放票日计算跨月且含时区 | 按规则时区计算提醒，不产生已错过提醒 | 跨月、时区 |
| R3-CASE-012 | 预约规则冲突 | 同一 POI、票种存在重叠生效区间 | 暂停自动发布并进入人工复核 | 冲突、并发发布 |
