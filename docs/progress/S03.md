## 实际验证

以下命令已在本次交付中执行，结果为实际结果，不以空测试代替验收：

```text
mvn -f backend\pom.xml test
mvn -f backend\pom.xml verify
mvn -f backend\pom.xml spring-boot:run '-Dspring-boot.run.profiles=mock' '-Dspring-boot.run.arguments=--server.port=18080'
Invoke-WebRequest -UseBasicParsing http://localhost:18080/actuator/health
git diff --check
git status --short --branch
```

实际结果：

- `mvn -f backend\pom.xml test`：通过，5 tests，0 failures，0 errors。
- `mvn -f backend\pom.xml verify`：通过，包含 Java/Maven Enforcer、编译、上述 5 个测试、打包和 Spring Boot 重打包。
- Mock 启动：通过，Tomcat 在 `18080` 启动；健康检查返回 HTTP 200、`status=UP`、`profiles=mock`、`databaseMode=disabled`、`externalServices=disabled`；随后已停止进程。
- `git diff --check`：通过。
- `git status --short --branch`：分支为 `feature/S03-backend`，仅包含本次 S03 后端交付文件和未提交新增文件。

依赖检查：`mvn -f backend\pom.xml dependency:tree '-DoutputType=text' '-Dscope=runtime' '-Dincludes=org.springframework.boot,org.flywaydb,com.mysql'` 已通过；解析到 Spring Boot 3.5.16、Flyway 11.7.2 和 MySQL Connector/J 9.7.0。

MySQL 空库启动验证依赖本机可用的 MySQL 8 实例；若本次环境没有实例，必须明确记录为未运行，不得把 Mock 验证记为 MySQL/Flyway 真实验收。

## 风险、PENDING 与回滚

- PENDING：完整 S03 Gate 还需要 agent-service、frontend 和三端协作证据，由指挥 Agent 或其他负责人完成。
- PENDING：若本机没有 MySQL 8，真实空库启动、重复启动和数据库不可用时的日志验证无法执行。
- 风险：本机系统 PATH 的 `java` 命令可能指向 Java 8；Maven 必须使用 `JAVA_HOME` 指向 Java 21，并以 `mvn -version` 为准。
- 风险：CI 首次执行需要下载尚未缓存的 Maven 依赖；依赖解析失败时 CI 应失败，不得跳过验证。
- 回滚：删除本次新增的 backend 构建/源码/资源、backend CI 和本文件即可，不涉及数据库迁移、业务数据或冻结契约。
