- 清理：已停止两次后端进程，删除临时数据库；辅助 MySQL 实例 `13306` 已停止并删除临时目录，主 MySQL `3306` 服务保持运行。

复现时先在当前 PowerShell 进程设置 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_DATABASE`、`MYSQL_USERNAME` 和 `MYSQL_PASSWORD`，再执行：

