## 状态定义

| 状态 | 含义 |
|---|---|
| 未开始 | 尚未执行该步骤 |
| 进行中 | 已开始，但仍有验收项或阻断项未关闭 |
| 已完成 | 依赖满足、交付齐全、适用检查真实通过且无阻断 `PENDING` |
| 已阻塞 | 依赖 Gate、外部账号或必须由负责人决策的事项未解决 |
