## 边界确认

- Java 是 MySQL 唯一业务写入方。
- 任务、报价、预扣、状态、事件和 Outbox 在同一事务。
- 失败结果不推进成功状态，重试耗尽后终止并幂等退款。
- MySQL 是事实源，Redis 只负责消息传递。
- 队列键使用 `queue:v1:task:{task_id}`，未混用缓存或限流前缀。
- 进度流执行归属校验，支持单调序号、断线补拉和终态关闭。
- 未越界实现完整模型网关、路线智能体、天气智能体或正式前端。
