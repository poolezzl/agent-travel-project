## 关键设计

- **明示 Mock 的三重防线**：① `DemoNotice` 横幅常驻顶部；② 所有点位/数值/文案显式携带 `Mock / 示例 / 估算 / 待核验 / unknown` 标识（fixture 层与组件层双重保证）；③ Mock 状态选择器只在 `__APP_PROFILE__ === 'mock' && VITE_ENABLE_MOCK === 'true'` 时渲染，production 构建不包含该入口。
- **本地状态机**：`status: success | loading | empty | partial | error` 为单一事实来源；模拟进度由 `setTimeout` 序列驱动并在 `onBeforeUnmount` 清理；提交期间按钮禁用防止重复触发。
- **降级不隐藏**：`degraded_fields`、`error_code`、`message` 与 `source_metadata` 在「契约信封」区块显式展示；空集合渲染空态说明，不用占位事实补齐。
- **可访问性**：原生表单控件 + label、`role="alert"` 错误摘要、`aria-live` 状态播报、可见焦点环、320px 窄屏无横向溢出、`prefers-reduced-motion` 关闭动画。
- **不引入未同意的运行时依赖**：仅新增 `@playwright/test` 开发依赖；无图表库、地图 SDK 或图标包。

### 本地行尾说明（format:check 相关）

本机 Git `core.autocrlf=true` 使检出文件为 CRLF，而 Prettier 默认 `endOfLine: "lf"`，因此 `prettier --check .`
会对**所有**检出文件报格式问题。经 `git show HEAD:<file> | prettier --check --stdin-filepath` 验证，
S03 原有文件内容本就合规，属于本地检出行尾问题而非真实格式问题；已用 `prettier --write` 将工作区统一为 LF
（`git add` 归一化后这些文件不出现在 diff 中，仓库内容零变化）。建议团队后续追加 `.gitattributes`
（如 `* text=auto eol=lf`）以消除 Windows 本地差异——该改动影响全仓库，需团队确认后另行提交，S07 不顺带修改。

## 来源 / 权限 / 幂等 / 并发 / 降级 / 隐私 / 回滚检查

- **来源**：全部 `source_metadata` 为合成 ID（`synthetic-*`），`freshness` 覆盖 `fresh/stale/unknown` 并显式展示取得时间；未引用任何真实 POI、图片或供应商数据。
- **权限**：页面不含登录态、角色判断或资源访问；状态选择器仅受构建期 Mock 防线控制。
- **幂等/并发**：提交为纯本地模拟，重复提交被禁用；无网络请求、无共享状态。
- **降级**：`degraded_fields` 与 `error_code` 显式展示（R6 规范禁止静默吞掉）；部分完成态同时可见数据与降级说明。
- **隐私**：不使用 `v-html`、不写入 localStorage、无真实用户数据、无外链图片。
- **回滚**：全部改动位于 `dev-r6-s07` 分支的 3 个独立 commit，可整体 revert；未触碰 master 与其他步骤文档。
