## 关键设计

- **ALG-04（POI 消歧）**：名字仅用于消歧，绝不作为主键；坐标/城市/坐标系一律取自 POI 端口，不信任候选输入；同名不自动合并。产出：缺上下文→澄清、无匹配→`SOURCE_UNAVAILABLE`、多匹配→带候选澄清、跨城→`CROSS_CITY`、缺坐标→`MISSING_COORDINATE`、非 GCJ02→`COORDINATE_SYSTEM_MISMATCH`。
- **ALG-05（确定性贪心 + 2-opt）**：O(n²) 距离矩阵只来自地图/路线端口（无 LLM）；每次 2-opt 交换必须同时降低总成本且保持可行；固定起终点不动；算法版本与 seed 集中在 `config.py`；tie-break 按索引升序，输出字节级一致；`total commute == sum(segment.duration_min)` 以断言强制；通勤/游玩/排队/用餐时间分离。
- **ALG-06（三级降级）**：固定顺序「新鲜精确缓存 → 直线估算（`is_estimated=true`）→ 不可用」；估算仅展示、不通过硬可行性 Gate；AUTH/QUOTA 不写负缓存；超时/跨城/不可达→结构化冲突；无解→`failed`。
- 退化输出遵守 envelope：`degraded` 必带 `degraded_fields` + `message`；`failed` 必带 `error_code` + `message`。

## 测试覆盖

- ALG-04：唯一名、poi_id 走端口、无匹配、缺名、同名歧义、跨城、缺坐标、坐标系不匹配。
- ALG-06：缓存命中保留源时间、过期回源、AUTH/QUOTA 不缓存、超时不可用、限流/脏/空→估算、估算需坐标。
- ALG-05/编排：固定起终点、`total == sum(segments)`、字节级确定性、去重、歧义、闭馆、午休、时间窗边界（恰好/超时）、零时长失败、不可达/超时失败、限流/脏/空降级、估算不通过硬 Gate、跨城/缺坐标/坐标系失败、负游玩时长拒绝、无点失败。

## 边界场景

- 成功：固定起终点、去重、字节级一致。
