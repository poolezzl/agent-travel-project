# S20 进度：R5 版本与确认

## 已完成

- 增加问答、局部修改、确认、回滚接口。
- 固定 `query/change/ambiguous` 三分类；`query` 不写版本、不扣积分；`ambiguous` 只返回澄清。
- `change` 强制基准版本、ETag、锁定项、影响日期、白名单 Agent、原子变更和确认门禁。
- 版本写入保存父版本、变更集、来源快照、Schema/模型/Prompt 版本和内容哈希。
- 使用数据库行锁与 ETag 条件更新；历史版本不可原地改，回滚创建新版本。
- 未提供新计划时复用父版本计划，避免未影响区块变化；局部修改不调用积分服务。
- 确认接口校验 `Idempotency-Key=confirmation_id`，按基准版本和变更指纹复用已创建版本。
- 变更路径必须落在 `affected_days` 白名单，成功建版返回 `CREATED` 和版本元数据。
- 非日期全局路径直接拒绝，避免绕过局部白名单。
