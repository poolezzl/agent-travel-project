## 边界与风险

- failed 样例只含稳定错误码和安全消息；部分/降级样例显式列出降级字段。
- 来源元数据允许 `unknown/stale`，但事实载荷不得无来源伪造；系统字段由网关注入。
- OpenAPI 的 `result` 在运行时按具体 Agent Schema 二次校验；本步骤未实现 Java/Python 消费者。
- 未解决的外部账号 PENDING（模型、高德、天气、部署机）只阻塞后续真实联调，不阻塞 S02。
