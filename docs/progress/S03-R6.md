## 前端设计

- 依赖固定在 `package.json` 和 npm lockfile；`npm ci` 是 CI/新环境安装入口。
- Vite 使用 `development`/`production`/`mock` mode；应用层将非 mock mode 显示为 `local`，避免 Vite 保留的 `.local` mode 冲突。
- `mock` 必须同时满足 mode=`mock` 和 `VITE_ENABLE_MOCK=true`；当前没有业务 fixture 或假 API。
- Pinia store 仅保存 profile/ready；不保存令牌、角色、余额、完整行程或偏好。
- Router 只有骨架路由；Element Plus 在 `main.ts` 统一注册；Vitest 使用 jsdom 和 Vue Test Utils。
