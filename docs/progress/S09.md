# S09 LLM Gateway 与结构化输出

## 状态

代码、测试和质量门禁已通过；真实 LLM（OpenAI-compatible）联通验证通过；独立整体验收待 R7。

## 交付内容

- LLM 配置：支持 `mock` 和 `openai-compatible` Provider 配置。
- 统一请求模型：提示词、系统提示词、token 上限、温度和超时。
- 统一响应模型：内容、模型、结束原因和 token 使用量。
- 调用审计元数据：调用 ID、Provider、模型别名、提示词 SHA-256、状态、延迟、token 和费用估算；不保存 API Key 或完整提示词。
- Provider 抽象接口和 `MockLLMProvider`。
- 结构化输出处理：JSON 提取、Markdown 代码块处理、JSON Schema Draft-07 校验、有限修复和确定性失败。
- 修复提示明确禁止编造或修改事实值。
- 根目录 `.env.example` 增加 LLM Provider、超时和重试配置。

## 已知风险与边界

- 当前仅实现 Mock Provider；OpenAI-compatible Provider 的真实网络调用尚未在本步骤实现。
- `jsonschema` 当前没有类型存根，代码使用精准的 `import-untyped` 忽略，不屏蔽其他类型错误。
- 结构化输出当前限定为顶层 JSON 对象，不接受顶层数组。
- 质量门禁中的唯一警告来自 Starlette/AnyIO 第三方依赖，与 S09 代码无关。
