## 场景与失败路径证据

| 场景 | 设计证据 |
|---|---|
| 成功 | 完整版本进入 `SUCCEEDED`，唯一确认预扣 |
| 空值/非法 | 模型空响应或 Schema 永久无效不得发布版本，失败后退款 |
| 超时 | 阶段时限与 180/60 秒全局 Deadline，确认独立 24 小时 |
| 重复/乱序 | attempt、事件序号、业务引用和状态 CAS 去重 |
| 取消 | 各运行态可取消；与版本事务 CAS 决胜；成功取消后退款 |
| 重启 | 从 MySQL 和新鲜 checkpoint 恢复，Redis 不作为事实 |
| 部分失败 | 仍可用且硬门禁通过才 `PARTIAL`，缺失可见并正常结算 |
| 确认 | 接受、拒绝、超时、重复和旧 ETag 均有确定迁移 |

完整迁移与测试断言见 [任务状态机](../architecture/任务状态机.md)，约束案例见 [冲突消解与确认规则](../architecture/冲突消解与确认规则.md)。
