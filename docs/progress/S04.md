## 实施前一致性修订

- `trip.city_id` 无法表达官方要求的城市列表、顺序和多城市串联；新增 `trip_city`，单城市也通过一行关联记录表达。
- `reminder_candidate.source_rule_id` 改为 `source_type` 加 `reservation_rule_id`/`source_snapshot_id`，由检查约束保证预约规则和天气来源可验证。
- `trip_version.content_hash` 统一为同一 `trip_id` 内唯一，跨行程允许重复。
- `trip`/`trip_version`、`poi`/`poi_snapshot`、`task_step`/`agent_result` 和 quote/task 的循环关系按建表阶段与 `ALTER TABLE` 延后外键。

上述修订已记录在 `docs/progress/S04-最终数据模型冻结单.md`，不改变业务 API 范围，不创建业务数据。

## 清理与风险

本轮使用 Compose 项目 `s04-fix-validation` 启动临时 MySQL 8.4.8、数据库和卷；验证结束执行 `docker compose down -v --remove-orphans`，容器、卷、网络残留均为 0。应用日志和临时 classpath 文件已删除，临时凭据仅存在于当前进程环境。

独立验收 Agent 已完成并通过本阶段验收。登记以下后续风险：

- 远程 CI Runner 尚未独立触发；本报告不把未实际触发的远程 workflow 结果当作已通过，后续 CI 仍需补验证。
- PowerShell 默认 `java -version` 显示 Java 8；本次 Maven 实际使用 Java 21.0.8 并通过 Enforcer，后续 CI 和本地验收仍需显式保证 Java 21。
- Flyway 对 MySQL 8.4 有兼容性提示；本次 MySQL 8.4.8 migrate、重复启动和 validate 均通过，后续仍需固定并复核 Flyway/MySQL 版本组合。

以上风险不影响本次 S04 数据模型与 Flyway Gate，但远程 CI 仍不得写成已通过。冻结单、S00-S03 文档、ADR、contracts、旧备份目录和 Gitee 教程未作为本轮归档修改内容。
